# 学習方法アンケートの独自分析と設計への翻訳

対象：提供された `学習方法と学習状況に関するアンケート__0917_自己学力123変換.xlsx` の `Sheet2`、2026年11月5日分析。

> ここに書かれた数値は個人情報を含まない**集計値**です。Excel原本・自由記述の個別回答は配布用アプリに含めません。

## 1. データの特徴と限界

- **135回答、38変数**。学年は1年39人／2年63人／3年33人。性別は女性88人／男性47人。
- 自己学力は「下位1／中位2／上位3」の主観回答。下位45／中位65／上位17／無回答8であり、実際のテスト成績ではありません。
- ポスターの調査対象 **154名** と、提供されたExcelの **135行** は一致しません。回答の抽出時点や除外基準を特定できないため、今回の数値は135行に限定します。
- 計画、開始固定、集中、意欲は各1設問の5件法。複数設問による検証済み尺度ではありません。
- すべて単一時点の自己申告。因果効果、改善率、保持・成績を直接測ったものではありません。
- 自由記述は原文のまま個人識別につながるおそれがあるため、アプリには取り込みません。

**分析上のポイント：**計画は集中度と、開始固定は学習時間と、それぞれ別の指標に対して調整後も関連が見られる。したがってアプリの計画機能は単なるToDo管理で終わらせず、開始予定・最初の1問・終了条件・実際の着手遅れを一体で扱う。

なお、回帰係数は因果効果ではなく、5件法を便宜的に線形の説明変数として用いた探索的推定です。未測定の交絡、多重比較、サンプルサイズ等に注意が必要です。

## 4. アプリの機能設計に直結させた判断

| 優先 | アプリ機能 | データ・研究上の根拠と測定対象 |
| --- | --- | --- |
| 最優先 | **学習前の3ステップ計画** | 計画×集中の関連。開始予定時刻、最初の一問、終了条件を記入 |
| 最優先 | **計画→実際の着手** | 開始固定×時間の関連。開始の遅れを測る |
| 最優先 | **タスクの実行・完了** | 計画して終わりでなく実行したかを確認 |
| 最優先 | **振り返り→翌日の最初の一問** | 自由記述に勉強法への不安や開始の困難がある |
| 高 | **学習／休憩タイマーと休憩後の戻り時間** | 休憩時間だけでは集中を説明しにくい。固定25/5を押しつけない |
| 高 | **翌日・7日後の理解チェック** | 「投入した時間」と「保持・正答」を分けるため（実験での測定が必要） |
| 高 | **7日間の本人の学習ログ** | 継続状態の把握。自己学力の推定にしない |
| 追加 | **ルール型の勉強法ヒント** | 「分からない」「始められない」「休憩から戻れない」などの問題に対応。予測AIとは呼ばない |
| 研究用 | **A/B条件のセッション割付と記録** | 小規模の比較研究へ移行するための基礎データ。表示は記述統計に限定 |
| 追加 | **JSONバックアップ・CSV書き出し** | 教員による事後分析・再現性・本人による保管のため |

## 5. 残した機能／あえて実装していない機能

- ポモドーロの**学習効果を保証する表示**は採用しない。アンケートは利用群・非利用群の関連であり、介入効果ではありません。
- **「最適な学習方法をAIが判定」**は未実装。今回の135件だけでは個人別の最適手法を識別できず、追加の介入データが必要です。
- **AIチャット**は未実装。GitHub Pagesのクライアント内に外部APIキーを埋め込むのは危険であり、利用するならバックエンドと認証・アクセス制御が必要です。
- **生徒間の記録共有・ランキング**は未実装。未成年のデータ共有には認証・同意・学校の運用規程などが不可欠で、GitHub Pages単体では安全に実現しづらいためです。
- 学力順位や睡眠・スマホの使用状況に基づく**評価・決めつけ**は行いません。

## 6. 次の検証に向けた提案

まず小規模試験として、同程度の課題と同じ学習可能時間のもとで、A（短い事前計画）とB（通常学習）を比較します。**主要指標は事前に1つ**選び（たとえば着手遅れ、または翌日の確認問題の正答率）、ベースラインの難易度や順序効果を含めて分析してください。学習方法を覚えることによる条件間の持ち越しがあり得るため、A/Bの交互使用だけで確定的な因果評価は行えません。
