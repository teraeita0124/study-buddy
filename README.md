# Study Buddy — 今日の一歩を、続く習慣に。

高校生の学習方法・学習状況に関する調査を踏まえた、**ブラウザだけで動く学習支援アプリ**です。学習計画、実際の着手、集中・休憩、振り返り、遅延チェックを一連の流れとして実装しています。

## 使い始める

### GitHub Pagesへ公開（推奨）

1. このフォルダの `index.html`、`styles.css`、`app.js`、`core.mjs`、`manifest.webmanifest`、`sw.js`、`icon.svg` をGitHubリポジトリの公開対象ディレクトリへ配置する。新しいリポジトリにも、既存の `study-buddy` にも適用可能です。既存のソースはバックアップしてください。
2. GitHubの **Settings → Pages** から **Deploy from a branch** を選択し、公開するブランチとフォルダ（root または docs）を指定する。
3. 表示された GitHub Pages のURLを開く。HTTPS環境ではオフライン用Service Workerの登録が行われます。

> アプリの`index.html`を直接ダブルクリックする場合は、ES Modulesの読み込みがブラウザのセキュリティ設定でブロックされることがあります。GitHub PagesまたはローカルHTTPサーバーで使ってください。

### ローカルで動かす

```bash
cd study-buddy-research
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。外部パッケージやビルド作業は不要です。

## 実装した機能

| 画面 | 主な機能 |
| --- | --- |
| ホーム | 当日の目標、タスク進捗、7日間の棒グラフ、振り返りに基づく提案 |
| 学習計画 | 開始予定、最初の一問、終了条件、科目別タスク、完了状況 |
| 集中タイマー | 可変の集中・休憩時間、途中での一時停止、着手遅れ、休憩後の戻りの遅れ、集中自己評価、中断回数 |
| 振り返り | 今日できたこと、つまずき、次にすること、翌日・7日後の理解確認 |
| 学習記録・比較 | 7日間の学習時間、自己評価平均、確認問題の正答率、探索的なA/B比較 |
| 勉強法のヒント | 開始・方法・休憩・集中・成果の悩み別ルール型ガイド |
| 設定・データ管理 | 集中時間や休憩時間の変更、JSONバックアップ・復元、CSV出力、端末データ削除 |

### おすすめの1日の使い方

1. 「学習計画」で**開始予定時刻・最初の一問・終了条件**を記入。
2. その日の課題を追加し、「集中タイマー」で学習。
3. セッション終了時に集中度や中断回数を記録。必要なら翌日・7日後の確認を登録。
4. 休憩が終わったら「学習に戻った」を押し、戻るまでの遅れを記録。
5. 1日の終わりに「振り返り」を記入し、次の日の最初の一手につなげる。

## 比較研究モードについて

「学習記録・比較」から有効にすると、開始時に A（3点の短い計画）/ B（普段通り）を2回1組でランダムに割り付けます。研究条件を有効にする前に、科目・課題難度・利用時間などをなるべく揃える研究計画を作ってください。**比較画面は記述統計のみで、因果効果を示しません。** 同一人の繰り返しや持ち越しを考慮するため、研究発表時には適切な実験デザインと解析が必要です。

## 保存・プライバシー

- プロフィール、計画、タスク、セッション、確認問題、振り返りは**このブラウザのLocalStorageにのみ保存**。外部送信・アカウント・分析トラッカーなし。
- 同じPCの異なるブラウザやスマートフォンには自動同期されません。ブラウザデータを消すと記録も失われるため、定期的にJSONバックアップを出力してください。
- 共有端末では次に使う人が記録を見られます。学校の共用端末で個人の学習内容を保存する場合は運用に注意してください。
- 生徒の元アンケートExcelと原文回答は**配布物に含めません**。アプリもアンケートExcelを自動で読み込んだり、他の生徒と共有したりしません。
- 通知・アラーム・バックグラウンド動作はブラウザや端末の仕様に左右されます。タイマーの実時間は保存しますが、通知や音声の保証はありません。
- リッチなAI会話や生徒同士の交流機能は意図的に未搭載です。追加する場合には安全な認証・サーバー・運用方針が必要です。

## 研究からの根拠

`analysis/ANALYSIS.md` に、Excelの135行を独自に再集計した数値・頑健回帰・限界・実装の優先順位を記載しています。`analysis/reanalyze.py` で元Excelから結果を再計算できます（別途 `artifact_tool numpy scipy statsmodels` が必要）。

## 開発・動作確認

- バニラJavaScript / ES Modules。依存ライブラリなし。GitHub Pages対応。オフラインキャッシュ（HTTPS）。
- 純粋関数のテストは `node --test tests/core.test.mjs`。
- UI動作確認：学習計画保存、タスク追加、タイマー開始・終了、振り返り保存、A/B切替、JSON書き出し、スマートフォン表示をChromiumで検証。
